# Simple-calculator-Java
This is a basic console-based calculator written in Java.
It allows the user to perform simple arithmetic operations by entering two numbers and choosing an operator. This project is used to show my learning of java by integrating if-statements in conjunction with swtiches. 

The project demonstrates:
- User input using Scanner
- Variables and data types
- switch statements
- Basic error handling
- Mathematical operations using Math.pow
- Formatted output with printf

Features: 
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Exponentiation (^)
- Prevents division by zero
- Displays clear error messages for invalid operators
- Outputs results formatted to 2 decimal places
